# Changelog

## v0.8.0 — 2026-10-31

- New **Electronic pet** app: adopt a cat or fox, six actions (feed/play/sleep/
  clean/pet/work), five stats, coins, poop, growth stages, death and re-adoption.
- Original 48×48 chibi sprites inspired by the reference images, generated by
  `tools/gen_pet_sprites.py`.
- NVS persistence plus offline ageing from the saved NTP timestamp; automatic
  minute partial refresh and 10-minute full refresh.
- Home menu now has 8 items (Pet added); web remote gets a 宠物 shortcut; serial
  `pet ...` commands.
- Docs: [PET.md](PET.md).

## v0.7.1 — 2026-10-31

- News category screen: added a “新闻分类” heading and source subtitle instead of
  a blank top area; status bar shows the category count.
- News list: 6 headlines per page with two-line wrapped titles (full width), a
  scroll offset and a `position/total` counter. Fixes the previous byte-based
  truncation that cut Chinese titles far too early.

## v0.7.0 — 2026-10-31

- New **News** app: Chinese RSS news by category (要闻/国内/国际/社会/体育/财经
  from China News Service, 科技 from ITHome).
- HTTPS fetch with limited streaming, RSS parsing and article HTML→text
  conversion; long articles paginate at 11 lines/page.
- Web remote gets a 新闻 shortcut; serial `app news`.
- Docs: [NEWS.md](NEWS.md).

## v0.6.2 — 2026-10-31

- Redrew Dou Dizhu suit icons procedurally: spade now has a clear pointed top,
  tapered body and stem; club uses three circles + stem; diamond stays a pure
  rhombus. Spade/diamond are much easier to tell apart.

## v0.6.1 — 2026-10-31

- Dou Dizhu card faces now use 7×9 pixel suit icons (spade/heart/diamond/club)
  instead of S/H/D/C letters; cards are 19×34 px. Jokers show 小/大 + star.

## v0.6.0 — 2026-10-31

- New **Games** menu: Gomoku (vs AI or 2-player) and simplified Dou Dizhu
  (vs AI or 3-player), controlled by the existing D-pad/OK/Back input.
- Gomoku heuristic AI (attack/defence pattern scoring, immediate win/block).
- Dou Dizhu: bidding, singles/pairs/triples/triple+single/bombs/rocket/single
  straights, simple legal-move AI.
- Web remote gets a 游戏 shortcut; serial `app games` / `app gomoku` / `app ddz`.
- Docs: [GAMES.md](GAMES.md).

## v0.5.2 — 2026-10-31

- WiFi diagnostics: `wifi status` now prints power-save mode, channel and TX power.
- `startNetworkServices()` forces `WiFi.setSleep(false)` after connect.
- Boot uses an explicit `wifiConnectPreferred()` (NVS credentials, then
  `secrets.h` fallback); the loop keeps a non-blocking `WiFi.reconnect()`.
- No functional change to storage/UI.

## v0.5.0 — 2026-10-31

- Repartitioned to a no-OTA layout: **3.5 MB app0** + **384 KB internal
  LittleFS** + 64 KB coredump; current firmware uses ~32%.
- Added `storage` module: internal `/int` LittleFS, external W25Q128 on HSPI
  mounted at `/ext` (JEDEC probe + external partition + LittleFS).
- Added `/api/storage` list/read/write/delete and serial
  `storage`/`ls`/`cat`/`write`/`rm` commands.
- Settings shows internal storage usage; docs: [STORAGE.md](STORAGE.md).

## v0.4.4 — 2026-10-31

- Fixed notes pagination: when a page ended exactly at a newline, that newline was
  kept as the first character of the next page and rendered as an empty first line
  on pages 2+. The newline is now consumed with the page break.

## v0.4.3 — 2026-10-31

- Notes: body moved up to y=28 and 12 lines/page (was y=40, 10 lines).
  Last line ends ~y=264, still above the y=270 hint bar.

## v0.4.2 — 2026-10-31

- Notes: removed the second title row; page number now sits in the top status bar
  to the left of the Wi-Fi icon.
- Notes body starts at y=40 and paginates at 10 lines/page.
- Notes/Image/Settings/QR placeholder bottom hint bars unified with Home
  (`hline y=270`, text `y=276`).

## v0.4.1 — 2026-10-31

- "Refresh / 全屏清残影" now uses the **HQ 50 Hz waveform** (`refreshHq`,
  ~4.15 s) instead of the standard 0.98 s waveform, for maximum ghost removal.
- API `POST /api/refresh`, serial `refresh`, and the web "高清清残影 4.1s"
  button all use the HQ path.
- Docs updated.

## v0.4.0 — 2026-10-30

- Custom device hostname, default `epaper42`; stored in NVS namespace `net`.
- Home status bar and Settings show the hostname; web card and serial `host`
  command update it.
- `GET/POST /api/host`; mDNS restarts immediately so `http://<name>.local` works;
  DHCP hostname applies after reboot.
- Validation: 1–32 chars `a-z 0-9 -`, no leading/trailing hyphen.
- Docs and screenshots updated; firmware ~86%.

## v0.3.0 — 2026-10-30

- New **QR** screen: text QR and Wi-Fi join QR (`WIFI:T:WPA;S:...;P:...;;`).
- Input from the web QR card, `POST /api/qr`, and serial `qr` / `qr wifi`.
- QR codes always render with the 50 Hz HQ waveform (~4.15 s), 4-module quiet
  zone, integer scaling and no status bar; the QR screen is static.
- Home menu now has five items; QR is the fourth.
- Wi-Fi QR escapes `\ ; , : "` and supports open networks (`T:nopass`).
- Added Nayuki QR Code generator (C, MIT); text/Wi-Fi codes decoded with
  `zxing-cpp` in testing.
- Docs: [QRCODE.md](QRCODE.md), API and serial-console updates; firmware ~85%.

## v0.2.0 — 2026-10-30

- USB serial console at 115200: `help`, `status`, `screen`, keys/apps/notes,
  panel control, reboot.
- Wi-Fi provisioning over serial (`wifi set` interactive, hidden password;
  `wifi scan`, `wifi forget`, `wifi reconnect`).
- Credentials now live in NVS namespace `wifi` and override `secrets.h`;
  flash without secrets and provision on first boot.
- `wifi scan` recovers from a failed-connect radio state by power-cycling the
  station and retrying.
- Docs: `docs/SERIAL_CONSOLE.md`; README quick start now uses serial provisioning.

## v0.1.0 — 2026-10-29

- Initial public release.
- Hardware: Waveshare ESP32 e-Paper Driver Board + WFT0420CZ15 (4.2″, UC8176).
- Fast driver: hardware SPI 10 MHz, 100 Hz PLL, three LUT classes, partial window
  refresh; full image 0.61 s device / 0.69–0.80 s round trip.
- Local UI: home, clock, notes, image, settings; 1bpp framebuffer; GB2312 +
  ASCII Unifont bitmaps; diff-based refresh.
- Web remote: 15 KB screen mirror, D-pad, app shortcuts, note editor.
- Minute-level clock with full refresh; 1 Hz partial clock removed after finding
  cumulative panel fading.
- Documentation of the stock-loader bottlenecks and waveform/PLL experiments.
